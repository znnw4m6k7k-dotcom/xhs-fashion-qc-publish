# 女装小红书整套发布 Skill｜中文说明书

## 这是什么

`xhs-fashion-qc-publish` 是一条女装小红书内容编排工作流。它负责把产品参考图、身份锚点和用户卖点整理成同一份可追溯任务，再依次协调生图、独立审图、文案、RedBeacon 自主添加审稿和人工确认后的发布。

它是“编排 Skill”，不是审图 Agent，也不是小红书账号或发布服务。审图与文案应由独立 Agent 完成，发布仍受账号登录、人工审核和精确发布预览约束。

## 安装后先检查

请让 Codex 在本机逐项核对并如实报告：

- 本 Skill 路径：`~/.codex/skills/xhs-fashion-qc-publish`。
- Codex 原生图像生成能力可用。
- 已安装 `xiaohongshu-fashion-prompt-draw`。
- 已安装独立审图 Agent“ 小红书商品图审图 ”。
- 已安装事实型文案 Agent“ 小红书事实型文案 ”。
- 需要入审或发布时，RedBeacon 的审稿、发布能力与目标小红书账号登录态可用。

缺少任何一项时，Codex 必须指出缺口；不能把“Skill 已安装”说成“整条链路已可运行”。

## 每次需要提供什么

- 明确的小红书账号与账号 ID；不能沿用上一款。
- 产品名称。
- 至少一张可读的权威服装参考图；结构重要时尽量提供正面、背面和细节。
- 同一人物身份锚点；没有锚点时不能承诺六图人物完全一致。
- 本款卖点与已知事实。
- 可选：希望采用的场景、构图或视觉参考。

价格、库存、销量、纤维比例、产地、护理承诺和未展示结构如未提供，都属于未知信息，不得补写。

## 标准流程

1. 建立产品事实卡，把可见事实、用户提供卖点和未知信息分开。
2. 默认生成 6 张 3:4 图片：5 张街拍、1 张对镜自拍。
3. 每张候选图交给独立审图 Agent。六张必须全部为 A；B 只允许一次定向返工，C 停止自动返工。
4. 文案 Agent 只根据事实卡、用户卖点和六张 A 图写标题、正文、标签与使用事实清单。
5. 使用 RedBeacon“自主添加笔记”进入指定账号审稿台，不调用 RedBeacon 生图、文案兜底或付费改写。
6. 用户确认精确发布预览后才发布。只有读回成功信号、本地归档和真实可用链接，才算发布完成。

## 第一次怎么说

```text
使用 $xhs-fashion-qc-publish 为这款女装制作小红书审稿包。账号是【账号名/ID】，产品名是【名称】，权威参考图在【路径】，人物锚点在【路径】，卖点是【内容】。先做依赖和输入检查；缺少事实就停下来问我，不要猜。先生成 5 张街拍和 1 张对镜自拍，六张全部通过独立 A 级审图后再写文案，并用 RedBeacon 自主添加进入审稿台。不要直接发布。
```

## 常用结果状态

- `READY_FOR_REVIEW`：六张 A 图、文案和清单齐全，已进入人工审稿。
- `BLOCKED`：缺输入、少于六张 A 图、账号不明确、登录失效、费用未知或需要未授权能力。
- `PUBLISHED`：发布成功信号、归档和真实链接均已回读。

“上传完成”“提交成功”或“打开了发布页”都不等于 `PUBLISHED`。

## 不会自动做的事

- 不从图片猜商品名、面料成分、库存或销售数据。
- 不绕过独立审图、人工审核或发布预览。
- 不直接写 RedBeacon 数据库，不修改浏览器 profile。
- 不保证第三方平台永远在线，也不把未知费用当成 0。
